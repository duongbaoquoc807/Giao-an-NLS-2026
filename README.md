# EduPlan AI - Soạn Giáo án CV 5512 tích hợp Năng lực số

Ứng dụng hỗ trợ giáo viên biên soạn Kế hoạch bài dạy chuẩn **Công văn 5512/BGDĐT-GDTrH** kết hợp **Khung Năng lực số người học GDPT 2018** sử dụng Google Gemini AI.

## 🚀 Tính năng nổi bật
- Chuẩn hóa đầy đủ Mục tiêu (Kiến thức, Năng lực chung & đặc thù, Năng lực số, Phẩm chất) và Thiết bị dạy học.
- Tiến trình 4 hoạt động chuẩn: Khởi động, Hình thành kiến thức, Luyện tập, Vận dụng (với 4 bước tổ chức thực hiện).
- Tích hợp công cụ số: Padlet, Kahoot, Quizizz, Canva, GeoGebra, PhET, Google Docs...
- Trợ lý AI sư phạm hỗ trợ trực tiếp.
- Xuất file Word (.docx) chuẩn thể thức hành chính A4.
- Tương thích 100% triển khai trên Vercel.

## 📦 Cài đặt & Khởi chạy

```bash
# Cài đặt thư viện
npm install

# Build dự án
npm run build

# Khởi chạy máy chủ
npm start
```
